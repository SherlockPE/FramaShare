🖼️ Framashare: the goal is to create an alternative to websites such as https://fr.slideshare.net/ or https://www.calameo.com/, which allow users to share (and view) PDF files, image carousels, or other types of content. epub is a good example.

Challenge: managing fine-grained sharing permissions.

Project to be coded “from scratch”, based on a brief specification and inspired by existing alternatives.
