# FramaShare

A local prototype for sharing and reading documents (PDF, EPUB) and albums in a secure and controlled manner. The project now uses a Monorepo architecture managed by **pnpm** with a Fastify/Prisma backend and a Vue 3/Vite frontend.

## 🚀 Prerequisites

- **Node.js** v22+
- **pnpm** v9+ (`npm install -g pnpm` or `corepack enable pnpm`)
- **Docker** and **Docker Compose** (for database and deployment)

## If you don't have pnpm installed on your machine
1. **Copy and paste this:**
   ```bash
   curl -fsSL https://get.pnpm.io | sh -
   ```

## 📦 Installation and Quick Start

1. **Install workspace dependencies:**
   ```bash
   pnpm install
   ```

2. **Start the database (PostgreSQL):**
   ```bash
   make db-up
   ```

3. **Run Prisma migrations and generate the DB client:**
   ```bash
   make db-migrate
   ```

4. **Start the development environment (concurrent Frontend + Backend):**
   ```bash
   make dev
   ```

The Frontend will be available at `http://localhost:5173` and the Backend at `http://localhost:3000`.

## 🛠️ Makefile Rules

The project includes an interactive `Makefile` (with animations and colors) to streamline everyday tasks.

| Command | Description |
| :--- | :--- |
| `make install` | Installs all monorepo dependencies (Frontend and Backend). |
| `make dev` | Starts development servers concurrently. |
| `make build` | Builds both projects for production (`dist/`). |
| `make db-up` | Starts Docker containers (PostgreSQL, Nginx, etc.) in the background. |
| `make db-down` | Stops Docker containers. |
| `make db-migrate` | Applies Prisma migrations to the DB and generates the Prisma Client for TypeScript. |
| `make clean` | Removes autogenerated folders (`dist/`, `build/`, Prisma client). Ideal for cleaning before committing to git. |
| `make fclean` | **Full Clean:** Same as `clean`, but also deletes **all** `node_modules` and `.lock` files. |
| `make re` | Reinstalls everything from scratch (runs `fclean` followed by `install`). |
| `make all` | (Default) Installs dependencies and starts the development environment. |

## 🏛️ Monorepo Structure

- `frontend/` - Web client built with **Vue 3** and **Vite**.
- `back/` - REST API built with **Fastify**, **Prisma** ORM (PostgreSQL).
- `nginx/` - Reverse proxy (for production/Docker).
- `docker-compose.yml` - Database orchestrator.
- `Makefile` - Shortcut scripts for automation.

## 🗄️ Local Database

You can access the database directly to inspect the tables created by Prisma using the following command (the admin password is in the backend's `.env` file):

```bash
docker compose exec -it db psql -U admin -d miapp_db
```
Once inside `psql`, you can use the following commands:
- `\dt` : View tables.
- `\d table_name` : View columns of a specific table.
- `\q` : Exit.
